# DP700 Quiz Web

A simple and interactive web-based Quiz Application built with HTML, CSS, and Vanilla JavaScript.

## 🚀 Live Demo

**[Play the Quiz Web Here!](https://macrisen.github.io/DP700_Quiz_App/)**

## 🛠️ Technologies Used

- **HTML5**: Structure and content layout.
- **CSS3**: Styling, animations, and responsive design.
- **JavaScript (Vanilla JS)**: Application logic, state management, and DOM manipulation.

## 📁 File Structure

- `index.html` - The main entry point and UI layout.
- `style.css` - Custom styles for the user interface.
- `app.js` - Core logic for handling user interactions and quiz progression.
- `questions_data.js` - The data file storing all the quiz questions, options, and correct answers.
- `images/` - Contains all media and image assets used within the quiz.

## 💻 How to Run Locally

To run this project on your local machine, you don't need any special server setup!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Macrisen/DP700_Quiz_App.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd DP700_Quiz_App
   ```
3. **Open the app:**
   Simply double-click the `index.html` file to open it in your default web browser, or use an extension like *Live Server* in VS Code for a better development experience.
